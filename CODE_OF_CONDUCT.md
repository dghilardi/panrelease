# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Please read the full text at the link above. In summary, we are committed to providing a welcoming and inclusive experience for everyone. We expect all participants to be respectful and constructive in their interactions.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it by opening an issue or contacting the project maintainers directly.
